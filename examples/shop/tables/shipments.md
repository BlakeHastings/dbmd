  - name: order_id

    nullable: false
    ref: orders.id

  - name: carrier
    type: text
    nullable: false
  - name: tracking_reference
    type: text
    nullable: true
  - name: weight_grams
    type: integer
    nullable: true
  - name: handheld_key
    type: text
    nullable: false
  - name: packed_at
    type: timestamptz
    nullable: false
    default: now()
  - name: shipped_at
    type: timestamptz
    nullable: true

  - name: shipments_order_idx
    columns: [order_id]
  - name: shipments_handheld_key
    columns: [handheld_key]

One row per parcel. An order can have several: a 1kg bag goes on its own because
of the courier's weight bands, and an order that mixes a coffee we have with one
that is waiting for Thursday ships in two halves rather than making the customer
wait for both.

**`shipped_at` being null is the whole state machine.** A row exists from the
moment the parcel is packed, and `shipped_at` is stamped when the courier scans
it. Between those two, the parcel is in the depot: it is ours, it counts as
stock in the building, and `stock_movements` has not recorded anything for it
yet. Reading "has this shipped" as "does a shipments row exist" is the mistake
this table invites, and it has been made twice.

`handheld_key` is an idempotency key generated by the depot's handheld scanner.
The depot wifi is bad enough that the app retries on a timeout it cannot tell
from a failure, so the same pack action arrives two or three times, minutes
apart. The second insert loses to `shipments_handheld_key`, so a parcel packed
once is a parcel that ships once. Anything new that this app writes needs the
same treatment; see the group note.

`carrier` is free text and not a foreign key to a carriers table, because there
are two of them and there have been two of them for four years. When there is a
third, and it needs a contract number and a collection window, that is the day
to add the table.

`weight_grams` is what the courier billed us for, filled in when their invoice
arrives, which is why it is nullable and why it is often null for a fortnight.
It does not match the sum of the bags: it includes the box.
